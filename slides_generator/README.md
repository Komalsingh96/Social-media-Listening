# AI-Powered Slides Generator

Desktop application for generating PowerPoint presentations using OpenAI GPT API.

## Quick Start

```bash
pip install -r requirements.txt
export OPENAI_API_KEY='your-api-key'
python slides_generator_gui.py
```

## Features

- AI-powered content generation with GPT-4
- 6 professional themes
- Desktop GUI with tkinter
- CLI support
- Export to .pptx format

## Available Themes

professional, vibrant, minimalist, modern, ocean, sunset
